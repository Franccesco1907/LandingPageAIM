# LandingPageAIM

Landing page de AIM en React 16, basada en Open de Cruip.

- Instalar: `npm ci` con una versión de Node compatible con `react-scripts@3`.
- Desarrollo: `npm start`; abrir http://localhost:3000.
- Compilar: `npm run build`; salida en `build/`.
- Pruebas: `npm test -- --watchAll=false` (no hay casos de prueba versionados).

Contenido en `src/views/Home.js` y `src/components/sections/`; estilos en `src/assets/scss/`. `src/App.js` inicializa Google Analytics con `REACT_APP_GA_CODE`.
